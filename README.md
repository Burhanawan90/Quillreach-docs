# Quillreach help docs

Customer help for Quillreach, live at https://quillreach.com/docs (Mintlify).

- Pages are `.mdx` files; the sidebar is `docs.json`.
- Rules for what a page may say are in `AGENTS.md`.
- `node scripts/check-copy.mjs` runs in CI and blocks wording that must never go public.
- Merging to `main` publishes the site automatically.
